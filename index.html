A LITTLE CONTEXT.

Your message, ready to go.

Using message JSON

Export a message and use the JSON payload in your own Discord bot or webhook integration. JSON pasted into regular Discord chat will appear as text. Guildkit does not request your credentials or send messages.

Using Latch templates

Keep one embed with a title, description and color. Remove message text, fields, author, footer and media. Choose “Export for Latch”, then paste that file's JSON into Latch's /template import command. Preview it with /template preview, then publish using /template send. The import command accepts up to 6,000 JSON characters and requires Manage Messages.

Your privacy

Drafts and named templates stay in this browser's local storage. No analytics, external fonts, uploaded documents or remote previews. Shared computer? Use “Clear local data” when done. Local storage is not encrypted. Exported JSON contains your message text.

Scope

Guildkit is an independent tool, not affiliated with Discord. It creates message payloads and planning text, not a hosted bot. Markdown previews cover bold and inline code; mentions, media, links and timestamps are displayed without external requests. Timestamps use your device timezone; check times around daylight-saving transitions.
